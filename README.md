# SetLog2（筋トレ記録）

筋トレのセットを素早く記録し、前回との比較・自己ベスト・次回の提案まで自動で出すWebアプリです。
ビルド不要の静的サイト（PWA）で、データは端末のブラウザ内に保存されます。サーバーやアカウントは必要ありません。

## 起動方法
```
npm start        # http://localhost:8080 で開く
npm test         # 計算ロジックのテスト
```
GitHub Pages や Firebase Hosting などにそのまま置いても動きます。スマホでは「ホーム画面に追加」するとアプリとして使えます（オフライン対応）。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | ワークアウト開始、今週の回数（目標比）・ボリューム・継続週数、部位ごとの前回からの日数、マイメニュー、最近の記録 |
| 記録 | セットの入力と完了チェック、前回の値、次回の提案、自己ベスト判定、休憩タイマー、スーパーセット、ウォームアップ自動作成、プレート計算 |
| 履歴 | カレンダー（実施日を色付け）、種目での絞り込み、ワークアウトの詳細・編集・もう一度行う・テキストで共有 |
| 種目 | 部位別の一覧と検索、種目ごとの推移グラフ（推定1RM・最高重量・ボリューム・最多回数）、回数別の記録（1〜15RMの実績と推定）、記録一覧 |
| 分析 | 週ごとのボリューム・回数（8〜52週）、今週の部位別セット数（先週比）、体重の記録と7日平均 |
| 設定 | 単位（kg/lb・既存データの換算）、重量の刻み、既定の休憩、週の目標、RPE欄、音・バイブ・通知、画面消灯防止、バーとプレート、テーマ、バックアップ |

### 記録を速くする工夫
- **前回の値が薄字で入っている**ので、同じなら ✓ を押すだけで記録できます。数字を打つと上書きされます。
- 「前回」欄をタップすると前回の値をそのまま入力します。種目のメニューから「前回の値をすべて入力」もできます。
- 入力欄で Enter を押すと次の欄へ移動。フォーカスすると全選択されるので、すぐ打ち直せます。
- ✓ を押すと**休憩タイマーが自動で開始**（種目ごとに休憩時間を記憶）。終了時に音とバイブで知らせます。画面を閉じていても時刻基準で正しく進みます。
- 記録中は**画面が消えない**ようにします（対応ブラウザのみ・設定で切替）。
- 記録中に他の画面を見ても、下部に「記録中」バーが出て、ワンタップで戻れます。

### セットの種類
左端の番号をタップすると、種類の変更・複製・削除ができます。
- **通常**（番号表示）／**W** ウォームアップ（集計・自己ベストに含めない）／**D** ドロップセット／**F** 限界まで
- 「ドロップセットを追加」で、重量を20%下げたセットを直後に追加します。

### 次回の提案（自動で重量アップ）
前回の記録から、今回の重量と回数を提案します。「入力」を押すと未完了のセットに反映されます。
- **目標回数（例 8〜12回）を設定した種目**：前回、全セットで上限回数に届いていたら「＋刻み（例 2.5kg）・下限回数」を提案。届いていなければ同じ重量で回数を1回ずつ伸ばす提案をします（ダブルプログレッション）。
- **目標回数なし**：前回のRPEがすべて7以下（余裕あり）なら重量アップ、それ以外は前回と同じ。
- 目標回数は種目の「…」→「目標回数」、またはメニューの編集で設定します。

### 自己ベスト
- 推定1RM（Epley式：重量×(1＋回数÷30)）、最高重量、1回のボリューム、自重種目の最多回数を、過去の全記録と比べます。
- 更新したセットには 🏆 が付き、その場で通知します。終了画面・履歴にも件数を表示します。
- 初めて行う種目は比較対象がないため、自己ベストとして数えません。

### スーパーセット
種目の「…」→「次の種目とスーパーセットにする」。組んだ種目同士では休憩タイマーを開始せず、次の種目名を表示します。最後の種目で休憩に入ります。

### マイメニュー（テンプレート）
- ホームの「作成」、または終了時の「メニューとして保存」で登録。サンプル（Push/Pull/Legs）も追加できます。
- 開始すると、各種目の重量・回数欄に前回の値と提案が入った状態で始まります。
- メニューから始めたワークアウトは、終了時に「メニューを今回の内容で更新」できます。

### ツール
- **プレート計算**：目標重量から片側に付けるプレートを図で表示。足りない場合は差分を表示。ウォームアップの目安も出ます。
- **1RM計算**：重量と回数から推定1RMと、%ごとの重量・目安回数を表示。

### データ
- データはこの端末のブラウザ（localStorage）にだけ保存されます。ブラウザのデータを消すと消えるので、**定期的に「設定 → バックアップを書き出す」** をしてください。
- バックアップ（JSON）から復元すると、別の端末へ移行できます。
- CSV（日付・種目・部位・セット・重量・回数・RPE・推定1RM・メモ）で書き出して、Excelなどで分析できます。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（ライト／ダーク対応） |
| `js/app.js` | 画面の描画と操作 |
| `js/logic.js` | 計算（推定1RM、自己ベスト、提案、プレート、集計、書き出し）。DOMに依存しない |
| `js/store.js` | 保存（localStorage） |
| `sw.js` | オフライン用のキャッシュ |
| `tests/logic.test.mjs` | 計算ロジックのテスト |
