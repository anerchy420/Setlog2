# setlog2

友だちと「1時間ごとの2秒動画」で同じ1日をシェアし、1日の終わりにVlogにする、セットログ（setlog）の上位互換Webアプリです。
スマホのブラウザで動き、ホーム画面に追加するとアプリとして使えます（iPhone / Android / PC）。

## できること

### 本家と同じ体験
- **毎時の撮影通知**：通知が来たら2秒だけ撮影。1時間の枠につき1人1本（あとから過去の枠には出せない）。
- **ログ（グループ）**：招待リンク・6文字のコードで友だちを招待（最大20人）。
- **時間ごとの分割画面**：上の点（●）で時間を切り替え。投稿した人のマスで動画が流れ、まだの人はグレーのまま。自分のマスは「タップして撮影」。
- **リアクション**：スタンプがマスの上に貼られる。♡ はワンタップ。返信の矢印から動画に返信。
- **カレンダー・共有・チャット**：上部のボタンから。

### 上位互換としての追加機能
（友だち同士で毎日使う人が困りがちなこと・欲しくなることを前提に設計）

| 困りごと | setlog2 では |
|---|---|
| ログごとに何回も撮るのが面倒 | **1回撮ればまとめて複数のログに投稿**（投稿先をチップで選ぶ） |
| 失敗した…でも撮り直せない | **送る前なら撮り直せる**。送ったあとは本家同様に固定（削除してその時間内に撮り直すことは可） |
| 撮り忘れる | **毎時45分のリマインド**（まだ撮っていない人だけ）／友だちを **👉つつく** と通知が届く |
| 夜中や授業中に通知が来る | **通知する時間帯**を自分で設定（例 8:00〜23:00、日またぎ可）。ログごとのミュートも |
| 通知が多すぎる／少なすぎる | 種類ごとにオン・オフ（毎時・リマインド・友だちの投稿・リアクション・チャット・つつく） |
| Vlogが選べない | **Vlogスタジオ**：時刻順／分割画面、縦（リール・TikTok）・横・正方形、フィルター5種、速さ、名前・ひとこと表示、動画の音、BGM（端末の音楽ファイル） |
| 自分だけの1日を残したい | **自分のVlog**（全ログから自分の動画だけで1本に） |
| 続ける理由がほしい | **連続日数🔥**、カレンダーに日ごとの表紙と投稿数、自分が投稿した日の印 |
| 誰が何で反応したか分からない | 動画を開くと **誰がどのスタンプか** が一覧で見える |
| 返信がどの動画の話か分からない | チャットに **動画のサムネ付き** で返信が残り、タップでその動画へ |
| 機種変更でデータが消える | **Googleアカウント連携**で引き継ぎ |
| アプリを入れたくない／PCでも見たい | **ブラウザで動く**（PWA）。PCでも閲覧・Vlog作成ができる |
| 荒らし・知らない人が入ってくる | 作成者が **参加受付の停止・コード変更・メンバーを外す** ことができる |

### プライバシー
- 動画はそのログのメンバーだけが見られます（Firestoreのルールで保護。招待コードの一覧は取得できません）。
- 自分の投稿はいつでも削除できます。ログから抜けると、そのログは見られなくなります。

## 使ってみる（デモモード）
設定なしで、この端末だけで動く「デモモード」になります。架空の友だち5人が投稿しているログ「ねむい組」で、撮影・リアクション・チャット・Vlog書き出しまで試せます。
```
npm start        # http://localhost:8080
npm test         # ロジックのテスト
```
カメラはHTTPSか localhost でしか使えません。別タブで `?demoUser=b` を付けて開くと、別の人として操作できます。

## 本番の設定（みんなで使う）

### 1. Firebase（無料プランでOK）
1. [Firebaseコンソール](https://console.firebase.google.com/) で新しいプロジェクトを作る（kitte とは別のプロジェクトにしてください。ルールが上書きされます）。
2. **Authentication** → ログイン方法で「匿名」と「Google」を有効にする。
3. **Firestore Database** を作成（本番モード・リージョンは `asia-northeast1` 推奨）。
4. プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、表示された設定値を `js/firebase-config.js` の `FIREBASE_CONFIG` に貼る。
5. ルールとインデックスを反映：
   ```
   npx firebase-tools login
   npx firebase-tools use --add      # 作ったプロジェクトを選ぶ
   npx firebase-tools deploy --only firestore
   ```
6. 公開：GitHub Pages（Settings → Pages → ブランチを選ぶ）か `npx firebase-tools deploy --only hosting`。
   公開したドメインを Authentication → 設定 → 承認済みドメイン に追加。

### 2. 通知（アプリを閉じていても届くようにする）
通知は GitHub Actions が5分おきに `scripts/notify.mjs` を実行して送ります（サーバー不要・公開リポジトリなら無料）。
1. 鍵を作る：`npm run vapid` → 表示された **Public Key** を `js/firebase-config.js` の `VAPID_PUBLIC_KEY` に貼る。
2. Firebase → プロジェクトの設定 → サービスアカウント →「新しい秘密鍵を生成」でJSONをダウンロード。
3. GitHub のリポジトリ → Settings → Secrets and variables → Actions に登録：
   | 名前 | 値 |
   |---|---|
   | `FIREBASE_SERVICE_ACCOUNT` | ダウンロードしたJSONの中身 |
   | `VAPID_PUBLIC_KEY` | 1 の Public Key |
   | `VAPID_PRIVATE_KEY` | 1 の Private Key |
   | `VAPID_SUBJECT` | `mailto:自分のメールアドレス` |
4. `.github/workflows/notify.yml` がデフォルトブランチにあると、5分おきに動きます（Actions タブから手動実行も可）。

**注意**
- iPhone は「共有 → ホーム画面に追加」したアイコンから開いたときだけ通知を受け取れます（iOS 16.4以降）。
- GitHub Actions の定期実行は混雑時に数分〜十数分遅れることがあります。毎時通知は各時の0〜29分の間に1回送ります。
- アプリを開いている間は、端末内でも毎時のお知らせ（バナー）が出ます。

## 容量の目安
動画は 640×360・約0.65Mbps の2秒（1本 100〜250KB）にしてFirestoreに保存します（Firebase Storage を使わないので無料プランのまま）。
Firestoreの無料枠は保存1GiB・読み取り1日5万回です。10人が毎日10本ずつ投稿すると約1年で上限に近づくので、その場合は古い日の動画を削除するか Blaze プランにしてください。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` / `css/style.css` | 画面の骨組みと見た目（ライト・ダーク） |
| `js/app.js` | 画面（ホーム・ログ・カメラ・ビューア・チャット・カレンダー・Vlog・設定） |
| `js/backend.js` | データ層（Firebase / デモ） |
| `js/camera.js` | 2秒の動画撮影（16:9に切り抜き・小さく圧縮） |
| `js/vlog.js` | Vlogの描画と書き出し（MP4対応ブラウザではMP4、それ以外はWebM） |
| `js/push.js` | 通知の許可とプッシュ購読 |
| `js/logic.js` | 時間枠・通知判定・招待コード・Vlog構成などの計算（ブラウザと通知スクリプトで共用） |
| `sw.js` | オフライン起動・プッシュ通知の表示 |
| `firestore.rules` / `firestore.indexes.json` | アクセス制御とインデックス |
| `scripts/notify.mjs` / `.github/workflows/notify.yml` | 通知サーバー |
| `tests/logic.test.mjs` | テスト |
