# setlog2

友だちと「1時間ごとの2秒動画」で同じ1日をシェアし、1日の終わりにVlogにする、セットログ（setlog）の上位互換Webアプリです。
自分のPCでサーバーを動かし、Cloudflare Tunnel でインターネットに公開します。スマホではホーム画面に追加してアプリとして使えます（iPhone / Android / PC）。

- [できること](#できること)
- [公開の全手順](#公開の全手順)（はじめての人向け・上から順に）

## できること

### 本家と同じ体験
- **毎時の撮影通知**：通知が来たら2秒だけ撮影。1時間の枠につき1人1本（終わった枠にはあとから出せない）。
- **ログ（グループ）**：招待リンク・6文字のコードで友だちを招待（最大20人）。
- **時間ごとの分割画面**：上の点（●）で時間を切り替え。投稿した人のマスで動画が流れ、まだの人はグレー。自分のマスは「タップして撮影」。
- **リアクション**：スタンプがマスに貼られる。♡ はワンタップ。返信の矢印から動画に返信。
- **カレンダー・共有（Vlog）・チャット**：上部のボタンから。

### 上位互換としての追加機能
| 困りごと | setlog2 では |
|---|---|
| ログごとに何回も撮るのが面倒 | **1回撮ればまとめて複数のログに投稿** |
| 失敗した…でも撮り直せない | **送る前なら撮り直せる**（送ったあとは固定。削除してその時間内に撮り直しは可） |
| 撮り忘れる | **毎時45分のリマインド**（まだの人だけ）／友だちを **👉つつく** と通知 |
| 夜中や授業中に通知が来る | **通知する時間帯**を設定（例 8:00〜23:00、日またぎ可）。ログごとのミュート |
| 通知が多い／少ない | 種類ごとにオン・オフ（毎時・リマインド・友だちの投稿・リアクション・チャット・つつく） |
| Vlogが選べない | **Vlogスタジオ**：時刻順／分割画面、縦（リール・TikTok）・横・正方形、フィルター5種、速さ、名前・ひとこと、動画の音、BGM |
| 自分だけの1日を残したい | **自分のVlog**（全ログから自分の動画だけで1本に） |
| 続ける理由がほしい | **連続日数🔥**、カレンダーに日ごとの表紙・投稿数・自分の投稿日 |
| 誰が何で反応したか分からない | 動画を開くと **誰がどのスタンプか** 一覧で見える |
| 返信がどの動画の話か分からない | チャットに **動画のサムネ付き** で返信が残り、タップでその動画へ |
| 機種変更でデータが消える | **引き継ぎコード**で別の端末へ（PC・タブレットと併用も可） |
| アプリを入れたくない | **ブラウザで動く**（PWA）。PCでも閲覧・Vlog作成 |
| 知らない人が入ってくる | **合言葉**で登録を制限／作成者が **参加受付の停止・コード変更・メンバーを外す** |
| 自分のデータを他社に預けたくない | **データは全部自分のPCの中**（`data` フォルダ） |

### 安全のための仕組み
- 動画・チャットは、そのログのメンバーだけが見られます（サーバーで毎回確認）。
- 投稿できるのは「今の時間の枠」だけです（時刻をごまかした過去投稿はサーバーが拒否）。
- サーバーは `127.0.0.1` で待ち受け、外からは Cloudflare Tunnel 経由でしか入れません。PCのポートを開ける必要はありません。
- 招待コードの総当たり・大量登録はアクセス数で制限しています。

## 公開の全手順

### 0. 用意するもの
| もの | 説明 |
|---|---|
| つけっぱなしにできるPC | Windows 10/11・Mac・Linux。スリープするとアプリが止まります |
| Cloudflare のアカウント（無料） | https://dash.cloudflare.com/sign-up |
| 独自ドメイン | 例 `example.com`。Cloudflare で買えます（.com で年 約1,500円）。**通知はURLに結び付くので、URLが変わらない独自ドメインが必要です** |

> まず試すだけなら、ドメインなしでも「4-B. お試し公開」で一時的なURLを作れます。

### 1. Node.js と Git を入れる
- **Node.js 22 LTS（22.13 以上）**：https://nodejs.org/ja から「LTS」をダウンロードしてインストール。
- **Git**：Windows は https://git-scm.com/download/win 、Mac はターミナルで `xcode-select --install`。

入ったか確認（Windows は「PowerShell」、Mac は「ターミナル」で）：
```
node -v      # v22.13.0 以上ならOK
git --version
```

### 2. setlog2 をダウンロードして起動
```
git clone https://github.com/anerchy420/Setlog2.git
cd Setlog2
npm install
```
設定ファイルを作ります：
```
# Windows (PowerShell)
copy .env.example .env
notepad .env

# Mac / Linux
cp .env.example .env
open -e .env        # Linux は nano .env
```
`.env` で最低限ここを書き換えて保存します：
```
PUBLIC_URL=https://setlog.あなたのドメイン
VAPID_SUBJECT=mailto:あなたのメールアドレス
SIGNUP_CODE=好きな合言葉        # 友だちだけが登録できるように（空なら誰でも登録可）
```
起動：
```
npm run server
```
`setlog2 サーバー起動: http://127.0.0.1:8787` と出たら、PCのブラウザで http://localhost:8787 を開いて画面が出ることを確認します（この画面はPC上でカメラも使えます）。
止めるときは `Ctrl + C`。

### 3. ドメインを Cloudflare に用意する
1. https://dash.cloudflare.com にログイン。
2. **ドメインを買う場合**：左メニュー「ドメイン登録」→「ドメインを登録」で好きなドメインを購入（自動で Cloudflare に追加されます）。
   **持っているドメインを使う場合**：「Webサイトを追加」→ 表示されるネームサーバー2つを、買ったサービス側で設定（反映まで最大1日）。

### 4-A. Cloudflare Tunnel で公開（本番）
1. ダッシュボード左メニューの **Zero Trust** を開く（初回はチーム名を決め、無料の「Free」プランを選ぶ）。
2. **ネットワーク（Networks）→ Tunnels →「トンネルを作成（Create a tunnel）」**。
3. 種類は **Cloudflared** を選び、名前を `setlog2` にして保存。
4. 「環境を選択」で自分のOSを選ぶと、インストール用のコマンドが表示されます。
   - **Windows**：表示されたリンクから `cloudflared` のインストーラー（.msi）を入れ、**管理者として開いた PowerShell** で、表示された
     `cloudflared.exe service install eyJ...（長い文字列）` を貼り付けて実行。
   - **Mac**：ターミナルで `brew install cloudflared`（Homebrew がなければ https://brew.sh ）→ 表示された
     `sudo cloudflared service install eyJ...` を実行。
   - **Linux**：表示されたコマンドをそのまま実行。

   画面下の「コネクタ」が **Connected（接続済み）** になれば成功。PCを再起動しても自動でつながります。
5. 「次へ」→ **パブリックホスト名（Public Hostname / 公開アプリケーションのルート）** を追加：
   | 項目 | 入力 |
   |---|---|
   | サブドメイン | `setlog` |
   | ドメイン | 自分のドメイン |
   | サービスのタイプ | `HTTP` |
   | URL | `localhost:8787` |
6. 保存して、スマホで `https://setlog.あなたのドメイン` を開く → setlog2 が出れば公開完了です。
7. おすすめ設定（Cloudflare ダッシュボード → 自分のドメイン）：
   - **速度 → 最適化 → Rocket Loader を「オフ」**（スクリプトを書き換えて動かなくなるため）
   - **SSL/TLS → エッジ証明書 →「常に HTTPS を使用」をオン**

> 画面の名前は Cloudflare の更新で変わることがあります。見つからないときは「Cloudflare Tunnel 作成」で検索すると最新の手順が出ます。

### 4-B. お試し公開（ドメインなし・一時的）
`cloudflared` を入れたあと、サーバーを起動した状態で別のウィンドウから：
```
cloudflared tunnel --url http://localhost:8787
```
`https://xxxx-xxxx.trycloudflare.com` というURLが表示され、すぐ使えます。
ただし **起動するたびにURLが変わり**、変わると通知の登録・ログイン状態もやり直しになります。本番は 4-A を使ってください。

### 5. サーバーを常に動かしておく（PC起動時に自動で開始）
`pm2` を使います（Windows / Mac / Linux 共通）。Setlog2 フォルダで：
```
npm install -g pm2
pm2 start server/server.mjs --name setlog2 --node-args="--disable-warning=ExperimentalWarning"
pm2 save
```
PC起動時に自動で開始する設定：
```
# Windows
npm install -g pm2-windows-startup
pm2-startup install

# Mac / Linux（表示されたコマンドをもう1行実行）
pm2 startup
```
よく使うコマンド：`pm2 status`（動いているか）、`pm2 logs setlog2`（ログ）、`pm2 restart setlog2`（再起動）。

あわせて **PCがスリープしないように** しておきます：
- Windows：設定 → システム → 電源 →「スリープ」を「なし」
- Mac：システム設定 → ディスプレイ（またはバッテリー）→ 詳細 →「ディスプレイがオフのときに自動でスリープさせない」をオン

### 6. スマホで使い始める
1. `https://setlog.あなたのドメイン` を開く。
2. ホーム画面に追加：
   - **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」→ 追加したアイコンから開く（**通知はこのアイコンから開いたときだけ届きます**。iOS 16.4以降）
   - **Android（Chrome）**：右上の︙ →「アプリをインストール」または「ホーム画面に追加」
3. 「はじめる」→（合言葉）→ 名前とアイコン。
4. ホームの「通知をオンにする」→ 許可 → 設定画面の「テスト通知を送る」で届くか確認。
5. 「ログを作る」→「送る」で友だちに招待リンクを送る。友だちはリンクを開くだけで参加画面になります（合言葉を設定した場合は一緒に伝える）。

これで公開完了です。

## 運用

### 更新
```
cd Setlog2
git pull
npm install
pm2 restart setlog2
```
スマホ側は次に開いたときに自動で新しい画面になります。

### バックアップ
```
npm run backup
```
`data/backups/日時/` にデータベースと動画がコピーされます（サーバーを動かしたままでOK）。外付けディスクやクラウドに `data/backups` をコピーしておくと安心です。
**戻し方**：`pm2 stop setlog2` → バックアップの `setlog.db` と `media` を `data/` に上書き → `pm2 start setlog2`。

### 容量の目安
動画は 640×360・2秒（1本 100〜250KB）。10人が毎日15本ずつ投稿すると 1日 約20MB、1年 約8GB です。
古い動画を自動で消すには `.env` の `RETENTION_DAYS`（例 `365`）を設定します。

### 困ったとき
| 症状 | 確認すること |
|---|---|
| URLを開くと Cloudflare のエラー（502 / 1033） | サーバーが止まっている → `pm2 status`。トンネルが切れている → Zero Trust の Tunnels で状態を確認 |
| 通知が来ない | iPhone はホーム画面のアイコンから開いているか／端末の設定でこのアプリ（Chrome）の通知が許可されているか／Android は電池の最適化を「制限なし」に／設定画面の「テスト通知」で届くか |
| カメラが使えない | `https://` のURLで開いているか（http では使えません。PCの `localhost` は可）／ブラウザのサイト設定でカメラ・マイクを許可 |
| 「この時間の枠はもう終わっています」 | 撮影してから送るまでに時間が空いた（枠が変わって10分以上）。もう一度撮って送る |
| 動画のVlogがInstagramに上げられない | WebM形式で書き出された可能性。iPhone の Safari か最新の Chrome で書き出すと MP4 になります |
| ポート 8787 が使われている | `.env` の `PORT` を変え、Cloudflare のURL（localhost:◯◯◯◯）も合わせる |

### 設定（`.env`）
| 名前 | 説明 | 既定 |
|---|---|---|
| `PORT` | 待ち受けるポート | `8787` |
| `HOST` | 待ち受けるアドレス（`127.0.0.1` 推奨） | `127.0.0.1` |
| `PUBLIC_URL` | 公開URL | なし |
| `VAPID_SUBJECT` | 通知の送信者の連絡先（`mailto:`） | `PUBLIC_URL` |
| `SIGNUP_CODE` | 登録に必要な合言葉（空なら誰でも） | なし |
| `RETENTION_DAYS` | この日数より古い動画を自動削除（0 = しない） | `0` |
| `DEFAULT_TZ` | 時間の基準（端末から届かないとき） | `Asia/Tokyo` |
| `DATA_DIR` | データの保存先 | `data` |

通知用の鍵は初回起動時に自動で作られ、データベースに保存されます（`data` を消すと全員の通知登録がやり直しになります）。

## 開発者向け
```
npm test          # ロジックとサーバーAPIのテスト
npm run server    # サーバー（http://localhost:8787）
npm run demo      # サーバーなしのデモモード（http://localhost:8080・架空の友だち入り）
```
| ファイル | 内容 |
|---|---|
| `server/server.mjs` | サーバー（画面の配信・API・リアルタイム更新・通知・自動削除）。データは SQLite（Node.js 内蔵） |
| `server/backup.mjs` | バックアップ |
| `index.html` / `css/style.css` | 画面の骨組みと見た目（ライト・ダーク） |
| `js/app.js` | 画面（ホーム・ログ・カメラ・ビューア・チャット・カレンダー・Vlog・設定） |
| `js/backend.js` | データ層（自前サーバー / Firebase / デモ を自動で切り替え） |
| `js/camera.js` | 2秒の動画撮影（16:9に切り抜き・小さく圧縮） |
| `js/vlog.js` | Vlogの描画と書き出し |
| `js/push.js` | 通知の許可とプッシュ購読 |
| `js/logic.js` | 時間枠・通知判定・招待コード・Vlog構成などの計算（画面とサーバーで共用） |
| `sw.js` | オフライン起動・プッシュ通知の表示 |
| `deploy/` | Cloudflare Tunnel（コマンド版）・systemd・Windows起動用の例 |
| `tests/` | テスト |

自前サーバーを使わず Firebase に置く構成も残してあります（`js/firebase-config.js` に設定を入れると Firebase モード。`firestore.rules`・`scripts/notify.mjs` を使用）。
